2. The E2B Isolated Code Sandbox

Nexus guarantees that no customer receives broken code. The Sandbox Executor (core/sandbox_executor.py) conducts a strict two-phase inspection:

  1. Static Compilation (Bytecode): Runs py_compile to catch missing brackets, invalid syntax, or unclosed strings.
  2. Subprocess Execution: Spawns an isolated Python runtime with cross-platform UTF-8 encoding and a strict 6,000ms execution cap.
  3. Automatic Quarantine: Any script that produces an uncaught exception is withheld from the store catalog until auto-corrected.

3. MemGPT 3-Tiered Memory Architecture

  • Working Memory: In-memory dictionary tracking current session goals and transient tasks.
  • Recall Memory (memory/recall_memory.json): Sliding window of the last 100 scouted niches, tool executions, and client responses.
  • Archival Memory (memory/archival_memory.json): Immutable corporate ground truth (owner information, MCB Juice phone numbers, verified product blueprints).

4. Serverless Read-Only Safeguard (Vercel Architecture)

Vercel serverless functions run on AWS Lambda where the application directory (/var/task) is strictly read-only. The storage subsystem (core/storage.py) transparently redirects state writes to /tmp whenever VERCEL=1 is detected, preventing filesystem crash errors and ensuring 100% cloud uptime.
